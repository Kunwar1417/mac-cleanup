# Mac Cleanup

One file that turns Claude Code into a careful cleanup assistant for your Mac. No app, no code.

**[See the demo](https://kunwar1417.github.io/mac-cleanup/)** (it replays a real cleanup; it can't see your Mac)

## How to use it

1. **Get Claude Code** from claude.com. You need a paid Claude plan.
2. **Make a folder** on your Desktop called `Mac Cleanup`.
3. **Download [CLAUDE.md](CLAUDE.md)** and put it in that folder. Keep the name exactly as it is.
   (Open the file, then click the download icon at the top right.)
4. **Open the folder in Claude Code** and type: *Help me free up space on my Mac*

Claude will ask whether you want a **quick clean** (safe junk only, about 5 minutes) or a **deep clean** (the full check).

## What it does

- **Sorts before it deletes**: Safe, Check with you, or Do not touch
- **Looks in the right places**: caches, old iPhone backups, installers in Downloads, Mail attachments, leftovers from deleted apps, big forgotten files
- **Knows your apps**: video app caches can go, projects stay (CapCut, Premiere, DaVinci, Final Cut, WhatsApp and more)
- **Has an undo**: personal files go to the Trash, so you can put them back
- **Checks your backup**: warns you if Time Machine hasn't run lately
- **Shows a clear report**: free space before and after, and what was cleared
- **Keeps it clean**: ends with 2–3 tips so your Mac doesn't fill up again
- Never uses admin access (`sudo`) without asking, and never touches system files, photos, projects or browser logins

## Before you start

- **Back up with Time Machine.** It's smart before any cleanup.
- **Read before you say yes.** You're always in control.
- **Make it yours.** Add folders you never want touched at the bottom of CLAUDE.md.
